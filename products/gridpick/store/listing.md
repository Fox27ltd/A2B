## Detailed description

Copy data off any web page without retyping it.

Gridpick finds the tables on a page — and the lists that aren't tables: product grids, search results, directory rows, league tables, anything a site renders from a loop — and turns them into a spreadsheet in one click.

WHAT IT DOES
• Finds every table and repeated list on the page automatically
• Names the columns for you (title, price, rating, link, image, date)
• Copies to your clipboard, or downloads a file
• Opens cleanly in Excel, Numbers, Google Sheets

FREE
• Every real HTML table on the page
• Copy or download as CSV
• Up to 100 rows

PRO
• Lists and grids that aren't HTML tables — the ones no other free tool reads
• Click to point at exactly what you want
• Excel (TSV), JSON and Markdown export
• Follow "next page" links and collect every page into one file
• Unlimited rows

WHO IT IS FOR
Anyone who has retyped a web page into a spreadsheet: researchers building lists, recruiters, ecommerce sellers checking competitor prices, analysts, journalists, estate and letting agents, procurement.

PRIVACY
Everything runs inside your browser. The page you are on is read locally and the file is built on your machine. Nothing is uploaded, no account is required, and there is no tracking of any kind. Gridpick asks for no permissions at all until you click it, and only ever reads the tab you clicked it on.

## Single purpose statement (required by review)
Gridpick has one purpose: to extract tabular data visible on the page the user is viewing and export it as a file. Every permission serves that purpose.

## Permission justifications (required by review)
- **activeTab** — reads the page the user clicked Gridpick on, in order to find its tables. Not granted until the click.
- **scripting** — injects the extraction code into that tab on demand. Nothing is injected on pages the user has not chosen.
- **storage** — stores the user's chosen export format and licence status locally.
- **downloads** — saves the generated CSV/JSON file the user asked for.
- **contextMenus** — adds a right-click entry to open Gridpick.
- **tabs and host access (optional, requested at the point of use)** — only when the user ticks "Follow next page links", so the extension can read the following pages of the same list. Never requested otherwise.
